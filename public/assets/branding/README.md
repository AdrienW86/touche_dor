# Logo Touche d’Or

Source : fichier `public/logo.png` fourni par le propriétaire du projet pendant cette intervention.

- `original-logo.png` : copie inchangée de la source.
- `touche-dor.webp` : copie sans perte en 1536 × 1024, utilisée partout dans la visite et le site.
